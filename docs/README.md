# getawaytransfers.com - Proje Dokümantasyonu

VIP transfer platformu: müşteri web sitesi, müşteri mobil uygulaması (iOS/Android), sürücü mobil uygulaması (iOS/Android) ve yönetim paneli (admin).

Bu klasör, proje kapsamı netleştirme görüşmelerinde alınan kararları içerir. Her karar ilgili dosyada tutulur.

## Dosya dizini

| Dosya | İçerik |
|---|---|
| kararlar.md | Alınan tüm iş ve teknik kararların kaydı |
| is_modeli.md | Hizmet modeli, roller, komisyon, sürücü ve araç kuralları |
| fiyatlandirma.md | Fiyat formülü, minimum ücret, gidiş-dönüş, iptal ve iade politikası |
| odeme.md | Ödeme sağlayıcıları, para birimi kuralları, sürücü ödemeleri |
| veritabani.md | PostgreSQL tabloları ve ilişkileri |
| ekranlar.md | Müşteri web, müşteri mobil, sürücü mobil ve admin ekran listesi |
| teknoloji.md | Teknoloji yığını ve servis seçimleri |
| yasal_ve_guvenlik.md | TÜRSAB, yetki belgeleri, KVKK, GDPR, mesafeli satış, veri güvenliği |
| mvp_plani.md | MVP ve tam sürüm kapsamı |
| acik_konular.md | Henüz netleşmeyen ve doğrulanması gereken maddeler |

## Proje sahibi

Geliştirme tek kişi tarafından, Claude ile yapılacak. Vergi ve operasyon maliyetlerini düşük tutmak önceliktir.
